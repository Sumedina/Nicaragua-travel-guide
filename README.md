# Nicaragua Travel Guide

Welcome to the **Nicaragua Travel Guide**, a React web application designed to help users explore the most interesting and beautiful places in Nicaragua. This project presents curated travel information, distances, approximate travel times, and personal ratings for each destination.

## Features

- **Home Page**: Displays recommended tourist destinations with name, location (department), star-based rating, distance and estimated travel time from Managua.
- **Guide Page**: Provides a clear and simple guide about how to use the website and highlights key features of each destination.
- **Information Page**: Explains the purpose of the website, clarifies that it is not an official tourism page and reassures users about privacy. The page mentions ongoing updates and future enhancements.

## Technologies Used

- React
- React Router DOM
- CSS for styling
